# datalogger-ecu-allroad
This project implements an embedded data acquisition system to read real-time engine data from the CAN/OBD2 bus of a 2002 Audi A6 Allroad 2.5 TDI, using an ESP32 microcontroller and an MCP2515 CAN controller. The system logs key parameters (RPM, coolant temperature, boost pressure) to an SD card with timestamps, enabling data-driven diagnostics of real vehicle faults instead of relying on guesswork. Developed as a personal portfolio project by an Electronics and Automation Engineering student, aimed at building practical experience for internships in the automotive sector.
